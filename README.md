# Courses and Learning Resources · 课程与学习资料

A shared course-materials repository for Xingmin Wang’s lab at Zhejiang University. All courses live here, with a separate directory for each course.

王兴民课题组的统一课程资料库。每门课程使用独立目录，提供课程说明、按章节组织的课件及相关学习资源，供学生和公开读者查阅。

## How to use / 使用方式

Open a course directory and choose a lecture to preview or download its PDF. More courses will be added as materials are prepared. Keep the attribution and source information supplied with each course.

进入课程目录后，可按章节预览或下载 PDF。后续课程继续加入本仓库；使用资料时请保留各课程原有署名与来源说明。
